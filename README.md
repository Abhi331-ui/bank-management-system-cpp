Bank Management System (C++)

📌 Description: 

A console-based Bank Management System built using C++.
It uses Object-Oriented Programming and file handling to manage multiple accounts.

🚀 Features: 

Create Account
Deposit & Withdraw
Delete Account
Delete All Accounts
Transaction History

🛠️ Technologies Used: 
C++
File Handling
OOP Concepts

▶️ How to Run: 
Compile:
g++ bank_management_system.cpp -o bank

Run:
./bank
